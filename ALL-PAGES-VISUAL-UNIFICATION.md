# All-page visual unification

## Scope

This update extends the existing theme-aware glass design to core pages and service pages, matching the visual language already applied to city and area guides.

## Pages covered

- Home remains on its existing layout and treatment.
- About: editorial card grid, values panels, CTA spacing.
- Services: responsive service-card grid with consistent image treatments.
- Service details: readable article panel, boxed overview, related-service chips, consistent hero treatment.
- Contact: responsive contact tiles, enquiry panel, and working-hours strip.
- Quote: themed intro and request card while preserving the shared quote modal flow.
- All cities: theme-aware hero, responsive city cards and directory panels.
- Vendor signup: themed partner callout.
- Shared sitewide related-content sections and footer: consistent surfaces, spacing, and high-contrast link styles.
- Existing city and area guides retain their repaired layouts.

## Preserved

No HTML content, routes, internal links, quote form fields/logic, navigation markup, Call button markup, WhatsApp button markup, contact destinations, or the random-theme palette definitions were intentionally changed. The changes are confined to the shared stylesheet and this report.

## Validation caveat

Static HTML/CSS/JS, local-link, and sitemap checks are included in `ALL-PAGES-VISUAL-VALIDATION.json`. A real-browser visual review should still be performed at desktop and mobile widths before production deployment.
