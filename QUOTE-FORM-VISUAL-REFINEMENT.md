# Quote form visual refinement

This update adds a theme-aware visual polish layer to the shared quote modal in `styles.css`.

Changes are scoped to `.quote-modal` and its quote-form descendants only: improved glass panel, header hierarchy, request number/date badge, three-step progress tracker, field labels and controls, button feedback, validation states, and success summary cards. Existing form markup, form field names, JavaScript submission logic, WhatsApp links, Call controls, and page content were not changed.

The update includes compact mobile rules and `prefers-reduced-motion` support.
