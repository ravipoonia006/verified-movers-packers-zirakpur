# Page-specific visual themes

Brand constants (all pages): logo, navy `#0A1628`, red `#E63946`, gold `#F4A261`, WhatsApp `918607227219`, phone, footer identity.

| Page | Body class | Visual direction |
|------|------------|------------------|
| `index.html` | `theme-home` | Cinematic premium: soft red/navy glows, dark trust strip, elevated service cards, rounded split panels |
| `about.html` | `theme-about` | Editorial: navy hero, left red border story cards, single-column values, spacious type |
| `contact.html` | `theme-contact` | Conversion: full-width **red** hero, centered contact tiles, bold form card with navy border |
| `quote.html` | `theme-quote` | Funnel: full dark navy chrome, red-bordered form card, minimal distraction |
| `all-cities.html` | `theme-cities` | Directory: diagonal line background, **offset hard-shadow** city cards (navy border + red shadow) |
| `movers-in-*.html` | `theme-city` | Local landing: warm paper background, dashed hero edge, ticket-style quote slip, dark gallery band, red FAQ rails |
| `vendor-signup.html` | `theme-vendor` | B2B: dark top band into light form surface |

Functionality preserved: forms, WhatsApp, tel links, SEO meta, sitemap, Vercel config.
